# CR Stays

Static CR Stays website, including the public Property Performance Analyzer frontend at `/analyzer/`.

Run local QA from the repository root:

```bash
python3 -m http.server 8080
```

Phase 5D integration details are documented in `docs/PPA-Phase5D-Website-Analyzer-Integration.md`.
Phase 5E adds the executive mobile Snapshot, saved result/unsubscribe pages and ES/EN presentation;
see `docs/PPA-Phase5E-Frontend-Snapshot.md` and `analyzer/README.md`.
